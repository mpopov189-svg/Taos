# Мишо AutoBot — готов автоматичен бот (първа версия)

**Какво е:** софтуер, който на всеки 90 секунди проверява BTC/EUR и **сам** решава дали да купи, да продаде или да изчака. Работи със Spot (без кредит, ливъридж и фючърси), с лимит до 50 EUR на покупка и само с една позиция. **Не е самообучаващ AI и няма гаранция за печалба.**

## Най-просто стартиране

1. На компютър с Python 3.10+: стартирай `python app.py`. Не са нужни външни Python библиотеки.
2. Отвори `http://localhost:8080` в браузъра. По подразбиране са **500 виртуални евро**. НЕ се изискват банкови карти и API ключове.
3. За да го наблюдаваш от iPhone по всяко време, трябва да го качиш на облачен сървър (например Render с Docker и постоянен диск). Включеният `render.yaml` е конфигурация за такова разгръщане. **Планът Starter и постоянният диск в тази конфигурация са платени — не активирай платена услуга без да прегледаш цената.** Стартира в режим `paper`, не с истински пари. При онлайн качване задължително се задава секретна `BOT_PASSWORD`.

## Какво прави сам

- Следи единствено двойката **BTC/EUR** (OKX Europe, публични пазарни данни).
- Използва предварително зададени правила EMA10/EMA30 и RSI14. Не трябва да избираш стратегия.
- Купува при възходящ тренд/умерен импулс, до 15% от наличния свободен EUR баланс (максимум 50 EUR на покупка).
- Продава при спад ~3% от входната цена, печалба ~5%, спад след достигане на върхова цена или обратен тренд.
- След сделка изчаква поне шест часа. Проверява пазара през 90 секунди; **не следи в реално време между проверките**.
- Демо сметката е локална симулация, а не истинска OKX демо сметка; има примерни такси 0,15% на операция. Не е реалистичен backtest.

## Свързване с OKX (не е нужно за първия тест)

Ботът е проектиран за европейската OKX API точка `https://eea.okx.com`. Съществуват два допълнителни режима:

- `MODE=okx_demo`: официална OKX демо среда (`x-simulated-trading: 1`) с отделни API ключове за **Demo Trading**.
- `MODE=live`: действителни пазарни поръчки с истински средства. **НЕ е активиран**; изисква изрична промяна на настройки, отделни реални API ключове, стабилно съхранение на състоянието и потвърждение на финансовия риск. **Не е проверяван с реални поръчки.**

За свързване създай **отделна празна търговска сметка/подсметка**, без съществуващи BTC позиции. Давай на API ключа само **Read + Trade**, **никога Withdraw**, и ако може го ограничи по статичен IP адрес. Създай и съхрани секретите в **environment variables на сървъра**, никога не ги пращай в чат. Трябват: `OKX_API_KEY`, `OKX_API_SECRET`, `OKX_API_PASSPHRASE`. Изисква се `BOT_PASSWORD`, а за real `ENABLE_LIVE=1`, `LIVE_RISK_ACK=I_ACCEPT_REAL_LOSSES`, `PERSISTENT_VOLUME_CONFIRMED=YES`, `DATA_DIR` на **истински постоянен диск**. Никога не сменяй MODE при съществуващи позиции или състояние: отделен DATA_DIR за всеки режим.

## Важни рискове и ограничения

- Кодът е MVP/прототип, а не професионално тествана система. Дори със стоп-загуба може да загубиш повече от 3% при волатилност, прекъсване, недостъпна борса, проскальзване и такси.
- Не използвай същата сметка за други ръчни сделки; ботът не може надеждно да различи чужди позиции. Режимът live умишлено отказва нови покупки, ако открие наличен чужд BTC. Не подава поръчки за теглене на средства.
- При неясен изход от API поръчка софтуерът спира и изисква проверка, вместо да повтори поръчката. При затваряне могат да останат минимални количества BTC заради такси/закръгляне.
- Риск от едновременно стартиране на два екземпляра върху една и съща сметка: **не стартирай повече от един**. Включеният Dashboard показва приблизителни резултати, без да е счетоводен отчет.
- Поддръжката на BTC-EUR, минималните количества и правилата на OKX за ЕС може да се променят. **Преди live режим са нужни проверка, допълнителни тестове и одобрение от теб.**

## Публикуване онлайн — подготвен пакет (без реални сделки)

1. Създай **частно GitHub хранилище** и качи файловете от ZIP в **корена му** (не целия ZIP като един файл). Не качвай `.env`, API ключове или пароли.
2. В Render избери **New → Blueprint**, свържи GitHub и посочи хранилището, съдържащо `render.yaml`.
3. Прегледай платения `starter` план и цената за постоянен диск **преди** да приемеш разгръщането.
4. При подканата за `BOT_PASSWORD` въведи **нова дълга уникална парола**. **Никога не я пишеш в GitHub или в чата.**
5. След успешното разгръщане отвори URL адреса от Render на телефона. Страницата ще поиска парола. Трябва да виждаш **„ДЕМО · Виртуални €“** и начални 500 €, не реален баланс.
6. Натисни Пауза при неясни сигнали или грешки. Може да мине продължително време без сделки, когато няма пазарен сигнал. Системата не е гарантирано печеливша.

**Важно:** За автоматично качване през ChatGPT е нужно изрично да свържеш профила си в Render (и, ако се ползва, GitHub). Самото предоставяне на ZIP не представлява реално публикуване.
