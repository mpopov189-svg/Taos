# Мишо AutoBot — демо

Тестово приложение с мобилен панел и 500 виртуални EUR. Използва публични пазарни данни за BTC/EUR и симулира сделките. Не изисква депозит или борсови API ключове.

Инструкции: [START_HERE_BG.md](START_HERE_BG.md).

Публикуваната услуга използва MODE=paper. Достъпът до панела е защитен с BOT_PASSWORD, която се задава само като environment variable в Render. На безплатния план приложението може да заспива, а демо историята се губи при рестартиране.
